## GraphOWL

A knowledge graph engine for enterprise metadata — stores, queries, reasons over and validates it as one connected graph.

- Website: [graphowl.app](https://graphowl.app)
- Live demo (password-protected, synthetic data): [demo.graphowl.app](https://demo.graphowl.app) — request access at connect@graphowl.app
- Releases, issues and questions: [graphowl/graphowl](https://github.com/graphowl/graphowl)

The product is proprietary and in early access. The source code is not published; documentation, the API specification, client libraries and runnable examples will appear here as they are released.
