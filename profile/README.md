## GraphOWL: the knowledge graph engine

Model, query, reason over and validate connected knowledge from your databases, documents and systems. Written in Rust; SPARQL, a Cypher subset, OWL 2 RL reasoning, validation, time travel and a built-in MCP server for AI agents.
